📱 Android Hacking — Mobile Penetration Testing

Learn how to test Android applications for security vulnerabilities. Covers APK reversing, ADB commands, app pentesting, and bypassing Android security controls.

1. ADB (Android Debug Bridge) Basics

ADB is the primary tool for interacting with Android devices from your computer.

Essential ADB Commands

# List connected devices
adb devices

# Install an APK
adb install app.apk

# Uninstall an app
adb uninstall com.example.app

# Pull files from device
adb pull /sdcard/data.txt

# Push files to device
adb push local.txt /sdcard/

# Open a shell on the device
adb shell

# List installed packages
adb shell pm list packages

# Start an activity
adb shell am start -n com.example.app/.MainActivity

2. APK Reversing & Decompilation

Tools & Commands

# Decompile APK with apktool
apktool d app.apk -o output_dir

# Convert APK to readable Java code (jadx)
jadx app.apk

# Extract resources
apktool d -r app.apk

# View AndroidManifest.xml
# Check for:
# - Exported activities (android:exported="true")
# - Permissions requested
# - Backup flag (android:allowBackup)
# - Debuggable flag

3. Common Android Vulnerabilities

Insecure Data Storage

# Check for hardcoded credentials
strings app.apk | grep -i "password\|apikey\|secret\|token"

# Check SharedPreferences on device
adb shell
cat /data/data/com.example.app/shared_prefs/*.xml

# Check SQLite databases
adb shell
sqlite3 /data/data/com.example.app/databases/app.db
.tables
SELECT * FROM users;

Root Detection Bypass

# Common root detection checks
# 1. Check if su binary exists
# 2. Check for root management apps
# 3. Check Build.TAGS
# 4. Check /system/app/Superuser.apk

# Bypass techniques:
# - Use Frida to hook root detection functions
# - Use Objection for runtime manipulation
# - Repackage APK after removing root checks

# Frida command to bypass root detection
frida -U -f com.example.app --no-pause -l bypass_root.js
